The counterfactual trap

You cannot learn from an outcome that never happened.

A logged dataset might say a user clicked a notification even when the model chose not to send it. A real device cannot observe that alternate world. Our simulator executes exactly one route and exposes only its factual consequence.

A

Interrupt now

The alert is sent immediately.

Observed click, dismiss, or ignore

B

Deliver later

The item enters the next digest.

Observed digest interaction

C

Archive silently

No notification is pushed.

Observed organic app open—or silence
xt → at → ot(at) → update

This is a contextual bandit, not batch classification.

At round t, the agent sees context x, commits to one action a, observes only that action’s outcome, and must improve before round t + 1. Accuracy and regret are measured on those live, pre-update decisions.

Online-SDFT

A richer learning signal from one real interaction.

The student acts without privileged state. Afterward, a teacher can use legal post-decision context and factual feedback to describe a full distribution over better routes.

Why reward-only REINFORCE struggles here

Each request permits one rollout, and silence often returns a harmless zero. With no teacher explanation and sparse reward, the policy drifts toward ARCHIVE—safe-looking behavior that accumulates high evaluator regret.
